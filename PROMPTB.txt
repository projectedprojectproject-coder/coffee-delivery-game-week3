[현재 상황]
첨부한 index.html은 커피를 받아 네 이웃에게 배달하는 게임이다.
HTML 파일 하나로 브라우저에서 실행된다.

[목표]
처음 플레이하는 사람이 화면 아래에서 조작 방법을 쉽게 읽게 하고 싶다.

[구체적인 변경]
1. 화면 아래 조작 안내를 다음 문구로 바꿔줘.
   “① 시작 누르기 → ② 방향키로 이동 → ③ 카페에서 E로 커피 받기 → ④ 이웃 앞에서 E로 배달하기”
2. 이 안내 문구의 글자 크기를 16px로 하고 진한 갈색으로 표시해줘.
3. 좁은 화면에서는 문구가 줄바꿈되게 해줘.

[유지할 것]
게임 속 마을, 캐릭터, 이동 속도, 배달 규칙, 버튼 기능은 유지해줘.
외부 라이브러리나 API를 추가하지 마.
파일을 나누지 말고 index.html 하나로 실행되게 해줘.

[완료 기준]
- 안내 문구가 요청한 순서와 글자 크기로 보인다.
- 화면이 좁아도 안내가 잘리지 않는다.
- 시작, 이동, 커피 받기, 배달, 일시정지, 초기화가 계속 작동한다.

[결과물]
파일을 직접 편집할 수 있으면 index.html을 수정해줘.
직접 편집할 수 없다면 생략 없이 전체 HTML 코드를 제공해줘.
끝에 변경한 점과 직접 확인하지 못한 점을 짧게 알려줘.
